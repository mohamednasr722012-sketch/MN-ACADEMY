# MN ACADEMY — المرحلة الأولى

تعلّم بذكاء.. تفوّق بثقة

## ما الذي يعمل الآن
- الصفحة الرئيسية بتصميم RTL عربي كامل ومتجاوب.
- MN AI: محادثة نصية تحتفظ بالسياق، ونسخ الردود، ومحادثة جديدة.
- تحليل صور الأسئلة والواجبات (jpg / png / webp حتى 5 ميجابايت).
- خادم Node.js/Express يحمي مفتاح Gemini، مع حد لعدد الطلبات (20 في الدقيقة).

## ما الذي لم يُنفّذ بعد
- الحسابات وتسجيل الدخول وقاعدة البيانات (PostgreSQL / Supabase).
- المناهج التفاعلية ولوحة الإدارة والاختبارات ولوحة الطالب.
- سجل المحادثات المحفوظ، وهو يحتاج قاعدة البيانات.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. داخل المجلد: `npm install`
3. انسخ `.env.example` إلى `.env` وضع المفتاح الجديد في `GEMINI_API_KEY`.
4. شغّل: `npm start` ثم افتح `http://localhost:3000`.

## تغيير النموذج
عدّل `GEMINI_MODEL` في ملف `.env` ثم أعد التشغيل، دون تعديل الكود.

## أمان
- المفتاح يُقرأ من `.env` على الخادم فقط، ولا يصل إلى المتصفح.
- لا تُسجَّل المفاتيح ولا محتوى الطلبات في السجلات.
- لا ترفع ملف `.env` إلى GitHub؛ الملف مستثنى في `.gitignore`.

## الإصدار 0.2 — الحسابات والمحادثات
- قاعدة بيانات SQLite تُنشأ تلقائيًا في مجلد `data/` عند أول تشغيل.
- إنشاء حساب وتسجيل دخول وخروج، وكلمات السر مشفرة بـ bcrypt، والجلسة في كوكي HttpOnly.
- المحادثات مع MN AI تُحفظ للمستخدم المسجل، وتُعرض وتُحذف من الواجهة.
- لوحة الطالب تعرض أرقامًا حقيقية من قاعدة البيانات.
- ملحوظة: `better-sqlite3` يحتاج أدوات بناء؛ على ويندوز غالبًا تعمل `npm install` مباشرة.
- لم يُنفّذ بعد: استعادة كلمة السر (تحتاج خدمة بريد)، والدروس والاختبارات، ولوحة الإدارة.
